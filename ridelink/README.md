# RideLink

A microservices-based ride-sharing platform.

## Project Structure

```
ridelink/
├── account-service/          # User account management service
├── driver-vehicle-service/   # Driver and vehicle management service
├── ride-management-service/  # Ride booking and management service
├── fare-payment-service/     # Fare calculation and payment service
├── docs/                     # Documentation
│   ├── diagrams/             # Architecture and design diagrams
│   ├── OpenAPI/              # OpenAPI/Swagger specifications
│   └── Postman/              # Postman collections for API testing
├── .github/workflows/        # CI/CD pipeline configurations
└── README.md                 # This file
```

## Services

| Service | Description |
|---------|-------------|
| **account-service** | Handles user registration, authentication, and profile management |
| **driver-vehicle-service** | Manages driver profiles and vehicle information |
| **ride-management-service** | Handles ride requests, matching, and trip lifecycle |
| **fare-payment-service** | Manages fare calculation, payments, and billing |
